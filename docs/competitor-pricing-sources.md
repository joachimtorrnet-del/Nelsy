# Competitor pricing sources

Every competitor figure used in the `/blog` comparison articles must match a line in this file.
Rule: official vendor pages only (pricing page or the vendor's own help center). No review sites, blogs, G2, Capterra or memory.
If a figure is not here, it does not go in an article.

Date checked for all rows below: **2026-11-27** unless marked otherwise.
Method: WebFetch of the URL. Quotes are the page text as returned by the fetch; layout-ambiguous items are flagged.
Prices exclude tax unless the page says otherwise.
