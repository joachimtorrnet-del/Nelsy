## Consolidation Rules

Before the full map, explicit decisions on near-identical keywords that should NOT get separate pages:

| Keyword group | Decision | Reason |
|--------------|----------|--------|
| "booking app for nail techs" + "nail tech booking app" + "nail tech scheduling app" | **One page: homepage** (`/`) | Same commercial intent, same SERP. Homepage already targets this cluster. |
| "nail tech booking software" + "nail tech booking website" | **One page** (`/nail-tech-booking-software`) | "Software" and "website" are synonyms in this context. Same buyer. |
| "online booking for nail techs" | **Consolidate into** `/nail-tech-booking-software` | Modifier-only variation. Not worth a separate URL. |
| "Fresha alternative for nail techs" + "Nelsy vs Fresha" | **One page** (`/fresha-alternative-nail-techs`) | Same intent: Fresha-to-Nelsy switcher. "Nelsy vs Fresha" redirects to it. |
| "Booksy alternative for nail techs" + "Nelsy vs Booksy" | **One page** (`/booksy-alternative-nail-techs`) | Same logic. |
| "GlossGenius alternative for nail techs" + "Nelsy vs GlossGenius" | **One page** (`/glossgenius-alternative-nail-techs`) | Same logic. |
| "nail tech deposit policy" + "nail tech cancellation policy" + "nail tech no show policy" | **One page** (`/nail-tech-deposit-and-cancellation-policy`) | These three are co-searched by the same person. One guide > three thin pages. |
| "nail tech pricing guide" + nail tech pricing calculator | **Guide** (`/nail-tech-pricing`) + **Tool** (`/tools/nail-tech-pricing-calculator`) | Different formats. Guide = editorial authority. Tool = link magnet. |
| "nail tech Instagram bio" + "nail tech Instagram bio generator" | **Tool** (`/tools/nail-tech-instagram-bio-generator`) | Tool satisfies both informational and tool intent. |
